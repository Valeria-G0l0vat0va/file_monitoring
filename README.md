# Цель работы
# Разработать программу с консольным интерфейсом, которая выполняет слежение за файлами и уведомляет пользователя об изменениях их состояния.
**Функциональные возможности:**

1)Добавление файлов в наблюдение - файл добавляется даже если физически отсутствует (будет отслеживаться его появление)

2)Удаление файлов из наблюдения - файл перестает отслеживаться

3)Просмотр списка наблюдаемых файлов - отображает все файлы с их текущим статусом

4)Автоматическое отслеживание изменений - программа проверяет файлы каждые 100 мс

5)Уведомления об изменениях: появление нового файла, исчезновение файла, изменение размера файла

**Сценарии поведения**

Файл существует - вывод информации о существовании и размере

Файл изменился - вывод сообщения об изменении и нового размера

Файл не существует - вывод сообщения об отсутствии файла

Файл появился - вывод сообщения о появлении и размере

Файл исчез - вывод сообщения о потере файла

**Требования к реализации**

1)Использовать сигнально-слотовый механизм Qt для уведомлений

2)Реализовать периодическую проверку состояния (каждые 100 мс)

3)Обеспечить возможность добавления/удаления файлов из наблюдения

4)При добавлении файла сразу сообщать его состояние

5)Обрабатывать ошибки (папка, отсутствие доступа, дубликаты)

6)Соблюдать принципы SOLID
